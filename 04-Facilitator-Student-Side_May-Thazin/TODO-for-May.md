## How to add a file

1. Open the folder on GitHub, for example `04-Facilitator-Student-Side_May-Thazin/02-Design`.
2. Choose **Add file**, then **Upload files**, drop your file in and commit directly to `main`.
3. Open the folder's `README.md` (pencil icon) and add one table row saying what the file is.

Keep the file names clear, with no spaces if you can (for example `Rules-v2-Definitions.pdf`). Add PDFs, images or Markdown rather than editable-only formats where possible.
