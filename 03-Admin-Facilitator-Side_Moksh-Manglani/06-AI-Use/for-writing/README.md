# For writing

Working documents made with AI to plan and write the final report and the poster. The report itself was written by Moksh in the official template; these are the aids around it.

| File | What it is |
|---|---|
| [`Project-Journal.md`](Project-Journal.md) | A dated record of decisions, problems and turning points in Part 1, condensed from the status documents kept through the project |
| [`StudyBuddy-Messaging.md`](StudyBuddy-Messaging.md) | The elevator pitch for Display Day, how the system works in plain words, the three-layer quality argument (screening, induction, support), and answers to the two objections raised at the conference |
| [`Final-Report-Writing-Brief.md`](Final-Report-Writing-Brief.md) | The standing rules for writing the report, built from supervisor feedback: back every claim with a source, say what was done personally, make the informal feedback credible |

**How the writing was done.** Ideas were first talked through and organised with AI, then turned into bullet points per section, which Moksh finalised before any prose was drafted. Drafts were edited section by section, keeping Moksh's own wording where he had already locked it. Every cited source was checked by hand.
