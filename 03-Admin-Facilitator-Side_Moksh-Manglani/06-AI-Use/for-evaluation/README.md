# For evaluation

Evaluation instruments made with AI. Download and open each file in a browser.

| File | What it is | Used in |
|---|---|---|
| [`nielsen-heuristics-review.html`](nielsen-heuristics-review.html) | The first heuristic review (September 2026): how the platform responds to each of Nielsen's ten heuristics | Report Table A1. The second, more critical pass is section E of [`05-Evaluation/EVALUATION_RESULTS.md`](../../05-Evaluation/EVALUATION_RESULTS.md) |
| [`ux-interview.html`](ux-interview.html) | A structured feedback instrument: open questions, the System Usability Scale, feature ratings, a task checklist and a Net Promoter question. Built for the planned interview study; responses are not included | Planning for informal feedback |

The test harness used for the technical evaluation was also written with AI (Claude Code), run against a local production build, and reviewed by Moksh before its results were used. It is kept with its results in [`05-Evaluation`](../../05-Evaluation/).
