AI Worksheet Generator

Replaces the old standalone worksheet-generator mock with a real, lesson-scoped, Claude-powered tool — agreed across two rounds of discussion before a line of it was built.

Status — Shipped Provider — Anthropic Claude Output — Real WORKSHEET block

1Summary

Admin opens a lesson and clicks "Generate AI worksheet." The system reads every block in that lesson — video transcripts, uploaded documents, activity/discussion/note instructions — and asks Claude to summarise the teaching scope. That summary goes to the admin for review and correction, then the admin picks question types and adds special instructions, Claude generates a structured worksheet, and the admin gets a full editor with an answer key before finalising it into a real block on the lesson.

2Confirmed decisions

The constraints that shaped everything downstream — settled before any code was written.

DecisionChoice
AI providerAnthropic Claude (@anthropic-ai/sdk)
Video understandingTranscript only — YouTube captions as text, fed to Claude. No native video-watching.
Video scopeYouTube only. Vimeo is skipped for understanding — no reliable public transcript route — but still shown as "no transcript available."
Document parsingPDF and DOCX text extraction. Other file types referenced by filename only, not parsed.
Transcript/parse failuresSurfaced to the admin on the pre-generate review screen as an explicit note — never a silent skip, never a hard failure.
Answer keyAlways included, always shown and editable before finalising.
RegenerateRe-runs from the saved/edited summary only — never re-fetches transcripts or re-parses documents.
Question types (v1)MCQ, short answer, long answer/essay, coloring/drawing (a themed prompt for the admin to act on, not a drawable asset).
Output destinationA new real WORKSHEET block, created only on "Add worksheet block." Never overwrites an existing block.
Old mock toolRetired — route and nav item removed, replaced entirely by this feature.

3Confirmed flow

  1. Admin, on a lesson's edit page, clicks "Generate AI worksheet."
  2. Loading screen — the server reads every block, fetches YouTube transcripts for video blocks, extracts text from PDF/DOCX attachments, and collects instructions from the rest. Sends it all to Claude for a scope summary.
  3. Pre-generate review — shows Claude's summary, directly editable. Any transcript or parse failures are listed as plain warnings. The admin then:
    • Selects one or more question types
    • Optionally adds special instructions — tone, difficulty, focus, count
    • Clicks Generate
  4. Claude generates a structured worksheet — title, student instructions, ordered questions, answer key — from the (possibly edited) summary plus the selected types and instructions.
  5. Editor screen — full preview with sidebar tools:
    • Edit any question's text, options, or answer
    • View and correct the answer key
    • Add, remove, or reorder questions manually
    • Regenerate — discards the draft, re-runs from the same summary, does not repeat step 2
  6. Admin clicks "Add worksheet block" — creates a real WORKSHEET block, appended to the lesson. Facilitators see it in the normal lesson flow from then on.

DOCX text extraction

New environment variable

ANTHROPIC_API_KEY

User-supplied, same constraint as Resend — an assistant can't create third-party accounts. Until set, generation returns a clear "not configured yet" state instead of crashing, so the rest of the UI stays testable.

AI-generated worksheet block shape

The existing admin-uploaded-file shape is unchanged and still supported. This second shape sits alongside it — the facilitator-side renderer handles both. 

{
  "generatedByAI": true,
  "title": "string",
  "studentInstructions": "string",
  "questions": [
    { "type": "mcq", "prompt": "string", "options": ["string", "..."], "correctIndex": 0 },
    { "type": "short_answer", "prompt": "string", "answer": "string" },
    { "type": "long_answer", "prompt": "string", "answer": "string" },
    { "type": "coloring", "prompt": "string" }
  ]
}
No schema migration needed — Block.content is already a flexible JSON column. This is a documented convention, not a structural change.

New and changed surfaces

/admin/lessons/[id]/worksheet-generator

The multi-step wizard — loading, review, editor. A full page, not a modal, given the depth of the flow.

analyzeLessonContent(lessonId)

Gathers block content, fetches transcripts, extracts documents, calls Claude for the scope summary. Returns {'{ summary, warnings[] }'}.

generateWorksheetDraft(...)

Calls Claude, returns the structured draft.

finalizeWorksheetBlock(lessonId, draft)

Creates the real Block row.

lib/youtube-transcript.ts · lib/document-text.ts · lib/ai-worksheet.ts

Isolated, single-purpose functions — each returns a result or an error, never throws past its own boundary.

State and cost

No database table for in-progress drafts — the wizard lives in client state until "Add worksheet block" is clicked; refreshing mid-wizard loses progress, accepted for v1. No rate limiting — admin-only, low volume, no objection raised when discussed.
